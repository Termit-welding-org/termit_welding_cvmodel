# Анализ качества сварки рамы квадроцикла с помощью ИИ

Проект по автоматическому контролю качества сварных швов квадроциклов с использованием компьютерного зрения и DVC для версионирования датасетов.

---

## 🚀 Запуск веб-приложения

Приложение доступно по ссылке:

👉 [https://termitweldingcvmodel-rnnob4uvhbt4ddhjizkzbm.streamlit.app/](https://termitweldingcvmodel-rnnob4uvhbt4ddhjizkzbm.streamlit.app/)

Функциональность:
- Загрузка изображения сварного шва
- Анализ качества (годен / дефект)
- Отображение вероятности и области дефекта
